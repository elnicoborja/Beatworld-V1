## Known hazards

- **OneDrive null-byte corruption:** the `src/**/*.js` files periodically get truncated mid-write by OneDrive sync, leaving trailing null bytes that crash the Vite parser. Fix: `for f in $(find src -name '*.js'); do tr -d '\0' < "$f" > "/tmp/$(basename "$f").stripped" && cp "/tmp/$(basename "$f").stripped" "$f"; done` then rebuild.
- **The Edit tool sometimes truncates files** mid-write under OneDrive sync. When it does, the build fails with "Failed to parse source for import analysis." The fix is to write the full file via shell heredoc, OR `head -N` the existing prefix and `cat >>` the missing tail.
